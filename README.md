# Kite — документація

Навчальний проєкт: вигаданий національний оператор експрес-доставки по Україні —
від створення накладної до видачі у відділенні чи поштоматі Kite Box.

**v1.4 · затверджено · 14.11.2026**

## Як читати

| Формат | Де | Для чого |
| ------ | -- | -------- |
| Одна сторінка | [`index.html`](index.html) | Повна документація з навігацією і схемами; відкривається у браузері без збірки |
| Markdown | [`docs/`](docs/README.md) | Той самий текст, розкладений по розділах — зручно читати просто на GitHub і правити по шматках |

Обидва формати описують одну й ту саму систему. `index.html` — джерело,
markdown у `docs/` згенеровано з нього.

## Що всередині

- **Продукт** — огляд системи, бренд, бізнес-модель і тарифи
- **Вимоги** — ролі, функціональні та нефункціональні вимоги
- **Архітектура** — 18 сервісів, схема баз даних, локальний стенд на Docker Compose
- **Домен** — стейт-машина посилки і подієва модель відстеження
- **Інтерфейси** — REST-контракт за шлюзом і сканування
- **AI** — прогноз дати, ризик неотримання, vision-конвеєр
- **План** — роадмап на 7 фаз, глосарій, ухвалені рішення

## Код

Документація описує систему, код якої живе окремими репозиторіями в тій самій
організації: по репозиторію на сервіс, контракти — у `kite-contracts`,
стенд — у `kite-infra`. Деталі — у розділах
[05](docs/03-arkhitektura/05-arkhitektura-i-karta-servisiv.md) і
[12](docs/03-arkhitektura/12-infrastruktura-i-lokalnyi-deploi.md).

## Збірка markdown-версії

`index.html` — джерело правди. Після правок у ньому перегенеруй `docs/`:

```bash
python3 tools/build-md-docs.py
```

Скрипт без залежностей; він перезаписує `docs/**/*.md` і `docs/assets/*.svg`,
тож правити їх руками не варто.
